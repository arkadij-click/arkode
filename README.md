# Редактор авторской письменности

Открыть `index.html` двойным щелчком: без сервера, без сети, без сборки.

## Что умеет

- Набор только знаками из каталога: первый внизу справа, дальше влево, перенос по ширине на строку выше.
- Пробел, ручной перенос (Enter), Backspace/Delete, курсор (щелчок, стрелки, Home/End), вставка в середину.
- Отмена/возврат (Ctrl+Z, Ctrl+Y), очистка тоже отменяется.
- Автосохранение черновика в браузере, сохранение и открытие JSON (`schemaVersion 0.1`, токены в порядке ввода).
- Экспорт PNG и SVG той же раскладкой, что и на экране.
- Предупреждение, если окошко конца текста стоит не в конце (ничего не удаляется само).
- Рамки вокруг знаков — включаются галочкой и не меняют текст.
- Подсказка по каждому знаку: ID, название, значение, статус из каталога.

## Глифы

Сейчас `glyphs.js` собран из `glyphs/source_crops` (фото A16): автоматически убраны бумага и
красные линии. Это временная графика.

Пересобрать: `python app/tools/build_glyphs.py` (нужен Pillow). Контрольный лист — `tools/preview.png`.

Чтобы поставить свои глифы, замените `glyphs.js`. Приложению нужен `window.GLYPH_SET.glyphs` —
массив объектов как минимум с `id`, `src` (PNG/SVG, можно data URL), `width`, `height`
(в «единицах исходника», типичная высота ячейки ≈ 100). Остальные поля (`name`, `meaning`, `status`,
`kind`, `endsText`, `variantOf`) нужны для подсказок и проверок. Если `id` сохранить,
все сохранённые документы откроются уже с новой графикой.
