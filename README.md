# Редактор авторской письменности

Открыть `index.html` двойным щелчком: без сервера, без сети, без сборки.

## Что умеет

- Набор только знаками из каталога: первый внизу справа, дальше влево, перенос по ширине на строку выше.
- Пробел, ручной перенос (Enter), Backspace/Delete, курсор (щелчок, стрелки, Home/End), вставка в середину.
- Отмена/возврат (Ctrl+Z, Ctrl+Y), очистка тоже отменяется.
- Автосохранение черновика в браузере, сохранение и открытие JSON (`schemaVersion 0.1`, токены в порядке ввода).
- Экспорт PNG и SVG той же раскладкой, что и на экране.
- Предупреждение, если окошко конца текста стоит не в конце (ничего не удаляется само).
- Подсказка по каждому знаку: ID, название, значение, статус из каталога.

## Глифы

Два начертания, переключаются в меню «Графика»:

- **прорисовка** (по умолчанию) — нарисованная гарнитура: `tools/design.py` описывает каждый знак
  геометрией (линии, окружности, кривые) на общей сетке: ячейка 100, верх знаков 24, базовая линия 80,
  точки на 15, одно перо толщиной 7. Устройство знаков взято с листа A16. Результат — `glyphs_svg/*.svg`,
  обзорный лист — `tools/specimen.svg`.
- **фото A16** — очищенные вырезки с фотографии, для сверки с оригиналом.

Пересборка (нужен Pillow):

```
python app/tools/design.py
python app/tools/build_glyphs.py
```

Чтобы поправить знак, меняется его функция `g_<ряд>_<столбец>` в `design.py`. ID знаков стабильны,
поэтому сохранённые документы открываются с любой графикой.
